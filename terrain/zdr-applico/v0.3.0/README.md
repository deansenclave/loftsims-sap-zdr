Open `index.html` in a browser to see the registered artifact inventory, filter by category, open each artifact, and export the inventory as JSON.

## Scope
This inventory includes the known artifacts in this repository and Terr-AI-n versions. It is a manifest, not an automated recursive discovery of all files or all historical conversations.
