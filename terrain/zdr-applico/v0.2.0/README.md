# ZDR Applico Terr-AI-n v0.2.0

This version introduces the **ZDR Applico-specific Terr-AI-nScape** as an integral part of the ZDR Applico Terr-AI-n. The Scape describes internal sub-Terr-AI-ns, interfaces, external dependencies, reusable artifacts and composition rules.

## Package contents
- `TERRAIN.json` — Terr-AI-n identity, implementation reference and governance
- `Terr-AI-nScape.json` — owned structure and sub-Terr-AI-n components
- `INTERFACES.json` — inbound/outbound interfaces and contract requirements
- `DEPENDENCIES.json` — external systems and cross-Terr-AI-n artifacts
- `COMPOSITION.json` — standalone, consumer, provider and composed modes
- `VALIDATION.json` — pending acceptance assertions

## Existing application
`../../../versions/v0.6.3/index.html` is the documented cumulative testing target (relative to repository root use `versions/v0.6.3/index.html`). No release application files are changed by this package.

## Evidence discipline
`documented` means present in repository documentation, not runtime-certified. `candidate` or `specified` does not imply an active connector, plugin or API. Live provider access and continuous assurance remain unverified.

## Governance
#HumansOnTop applies to this Terr-AI-n and all its sub-Terr-AI-ns. External access, contracts and composition require explicit authorization.
